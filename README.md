# software-quizz

Quiz site for revising software development concepts. The questions come from a personal
Notion library and are generated by rules at build time, with no LLM.

Requires Node 22.18 or later.

## Run

```bash
npm install
npm run dev
```

The site runs on http://localhost:3000.

## Test

```bash
npm run check
```

This runs the Prettier check, ESLint, the type-check and the Vitest unit tests. The end-to-end
tests run on the static build, on desktop and mobile:

```bash
npx playwright install chromium   # once
npm run test:e2e
```

Both need the data in `generated/` (see below).

## Sync the concepts

```bash
cp .env.example .env   # then fill in the two values
npm run sync
```

This writes `generated/concepts.json`. Then `npm run questions` builds the quiz in
`generated/questions.json`. The token comes from a read-only Notion integration that
can only see the Concepts database.

## Build

```bash
npm run generate
npm run preview
```

`generate` writes the static site to `.output/public`; `preview` serves it on http://localhost:4173.

## Deploy

`.github/workflows/deploy.yml` runs on every push to `main`, every Monday at 04:00 UTC (to pick up
new sheets) and on demand. It exports the concepts, runs the checks and the end-to-end tests, builds
a Docker image (Caddy serving the static site), pushes it to `ghcr.io/adrienitts/software-quizz` and
deploys it to the VPS over SSH, behind the front Caddy, at https://quiz.adrienitts.com.

Repository secrets: `NOTION_TOKEN`, `NOTION_CONCEPTS_DATA_SOURCE_ID`, `VPS_HOST`, `VPS_USER`,
`VPS_SSH_KEY` and `VPS_KNOWN_HOSTS`. The files to install on the VPS are in `deploy/vps/`.

Each image is tagged `sha-<commit>-run<number>`, because the weekly run rebuilds the same commit
with new data. To roll back, run the deploy key with an older tag:

```bash
ssh -i ~/.ssh/deploy_software_quizz adrien@<vps> "sha-1a2b3c4-run12"
```
